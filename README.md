# DoubleSCorporation — Смарт сүт

Цифровая платформа для молочной цепочки:

- **Производитель** — заявки на сдачу сырого молока  
- **Оптовик** — закупка у хозяйств и продажа переработчикам  
- **Переработчик** — спрос и мониторинг поставок  

## Как пользоваться

1. На старте выберите кабинет (роль).  
2. Работайте во вкладках своей роли.  
3. Сменить кабинет: **Кабинет → Сменить кабинет**.  

## Запуск

```bash
cd apps/mobile
npm install
npm run web
```
